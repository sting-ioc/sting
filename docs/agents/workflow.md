# Contribution workflow

- For commits and pull requests, follow [CONTRIBUTING.md](../../CONTRIBUTING.md) and the [Code of Conduct](../../CODE_OF_CONDUCT.md).
- Keep commits focused, use imperative subjects, and reference relevant issues.
- Update `CHANGELOG.md` for user-visible changes.
- Pull requests should describe the change, link relevant issues, and report behavioral tests. Include screenshots or generated artifacts when they help review.

For releases, use an explicit version and the scripts under `tools/release/`. Maintainers provide signing and publishing credentials; follow [Release](../development_process.md#release).
